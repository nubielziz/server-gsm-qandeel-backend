# P2.8 clock

Phase 2 add-on, done before Phase 3 (user request 2026-11-01). Read `_common.md` first. Goal: no code decides on the
wall clock directly and no test depends on wall-clock time, sleeps or WSL clock jumps.

## Build
1. **Clock** (`src/common/clock.ts`): an interface `Clock { now(): Date; nowMs(): number }`, the `SystemClock`, and a
   DI token `CLOCK` provided globally (one provider in the root modules of the API and the worker). Decision 031
   (`docs/decisions/031-clock.md`): what must use it and what may not.
2. **Use it everywhere a decision depends on time**: session absolute and idle expiry, touch throttling, pending-stage
   lifetimes, token expiry (invite, reset, verify, link, capability), TOTP checks (pass the epoch), IP-rule expiry,
   maintenance windows, rate-limit and lock bookkeeping that the code computes itself, webhook timestamp windows,
   cache TTL jitter and stale windows computed in code, job-run durations stored in the database, outbox lag, holds
   and anything else found by `rg "Date.now\(\)|new Date\(\)" src`. SQL that compares with `now()` to decide
   (expired sessions, tokens, rules) takes the clock's time as a parameter instead. Column defaults
   (`created_at default now()`) may stay. Pure elapsed-time measurements for metrics and logs (`performance.now()`)
   may stay; say so in decision 031.
3. **Lint rule**: forbid `Date.now()` and argument-less `new Date()` in `src/` outside `src/common/clock.ts`
   (`no-restricted-syntax` with a clear message).
4. **Tests**: `test/support/clock.ts` with a `TestClock` (`set(date)`, `advance(ms)`), injectable through
   `createTestApp({ clock })` and the infra harness. Convert every time-sensitive test (all `Bun.sleep` / timer waits
   and short TTL windows in `test/` and `src/**/*.spec.ts`) to controlled time. Where an external system keeps its own
   time (Redis TTLs, rate-limiter-flexible windows, BullMQ delays and schedulers), assert the TTL, delay or option the
   code set (`PTTL`, job options) instead of waiting for it; keep a real wait only where the test is about that
   external behaviour (the Docker restart test), with a one-line reason. Child-process tests may keep real time.
5. Remove the widened margins added earlier (security-guards session expiry, ip-rules expiry) in favour of controlled
   time.

## Done when
`bun run check` is green three times in a row; `rg "Bun.sleep" test src` shows only the documented external-time
cases; the lint rule passes; decision 031 exists.
